# Job Tracker

A full-stack MERN job application tracker where users can:

- Register/Login with JWT authentication
- Track job applications
- Update application status
- Upload resumes
- Delete applications
- Manage job types and progress

---

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Axios
- React Router DOM

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary

---

## Features

- User authentication
- Secure cookies
- CRUD operations
- Resume upload
- Status tracking
- Responsive UI
